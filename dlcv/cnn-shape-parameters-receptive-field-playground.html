Derivation card

Four formulas, one coherent trace

F_eff = D(F−1)+1
N_out = floor((N_in+2P−F_eff)/S)+1
weights = F² C_in C_out
biases = C_out, if included
conv MACs = H_out W_out F² C_in C_out
j_l = j_(l−1) S_l
r_l = r_(l−1)+(F_eff−1)j_(l−1)

Padding appears in output size but not in the interior theoretical RF size. Spatial size appears in compute but not in learned parameter count. These separations explain most Week 4 option traps.
