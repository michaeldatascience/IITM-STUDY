Key formulae

Point operator · 1×1
\( g(i,j)=h\big(f(i,j)\big) \)output depends on one input pixel
\( g = a\,f + b \)gain \(a\) = contrast, bias \(b\) = brightness (a 1×1 kernel is exactly gain \(a\))
Neighbourhood — the whole point
\( g(i,j)=\sum_{a,b} f(i+a,\,j+b)\,h(a,b)=f\otimes h \)cross-correlation: kernel as-is
\( g(i,j)=\sum_{a,b} f(i-a,\,j-b)\,h(a,b)=f*h \)convolution: same weights, reversed indexing
\( f*h = f\otimes\tilde h \)\(\tilde h\) = \(h\) rotated 180°. Both use the kernel weights — this is the only difference
\( h*\delta = h \)convolving with an impulse reproduces the kernel
Linear shift-invariant (LSI)
\( h\circ(f_0+f_1)=h\circ f_0 + h\circ f_1 \)superposition (linearity)
\( f(i{+}k,j{+}l)\;\Rightarrow\;(h\circ f)(i{+}k,j{+}l) \)shift-invariance: behaves the same everywhere
\( \textstyle\sum_{a,b} h(a,b) \) = DC gain1 preserves brightness · 0 keeps only edges
Design & frequency
\( K = v\,h^{\mathsf T},\quad 2K \text{ vs } K^2 \)separable kernel → two 1D passes instead of one 2D pass
\( G(x,y;\sigma)=\tfrac{1}{2\pi\sigma^2}\,e^{-(x^2+y^2)/2\sigma^2} \)the Gaussian (binomial kernels approximate it)
\( f*h \;\Leftrightarrow\; F\cdot H \)convolution theorem: filtering = multiply in frequency

Reading a kernel by eye

  • 1×1 → point operator: \(g=a\,f\), no neighbours (brightness/contrast).
  • All positive, sums to 1 → averaging / blur (low-pass). Box, Gaussian.
  • Big positive centre, negative surround → sharpen (sum 1) or edge (sum 0).
  • One side negative, other positive, zero middle → directional gradient; fires on edges running across it (Sobel-X → vertical edges).
  • Symmetric, sums to ~0 → second derivative (Laplacian): any rapid change, orientation-blind.
  • The sum of cells is the DC gain: 1 keeps brightness, 0 gives a pure edge map.

Six things to try

  1. Set kernel size to 1×1. That's a point operator — output = a·input, no neighbourhood. Switch between Identity / Brighten / Darken.
  2. Circle + Sobel-X + signed view. Left and right edges come out opposite colours. Flip Cross-correlation → Convolution: colours swap, because ∗ flips the kernel — but the same weights are still used (watch the products row).
  3. Type i=27, j=27 (at 28×28) to inspect the corner, then change Padding — see how the out-of-bounds cells (dashed) change.
  4. Box vs Gaussian at 5×5 on a circle; normalize on to preserve brightness.
  5. Checker + Box 5×5: the fine pattern washes out — low-pass in action.
  6. Hand-build a detector: clear the kernel, left column −1, right +1, middle 0. Predict, then look.
