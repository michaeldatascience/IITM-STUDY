First recovery surface

Formula and shape wall

Attention

Rows: Q=XWQ, K=XWK, V=XWV
S=QKT/sqrt(dk), A=softmax(S), O=AV

Official column-token form: H in Rd x T, Q=WQH, score QTK.

Standard MHA weights: 4dmodel2 without bias.

Language modelling

P(x1:T) = product P(xt | x<t)
NLL = -sum log p(target)
PPL = exp(mean NLL)

Sequence score is a product of conditional probabilities, or a sum of log probabilities.

Normalization and position

LN(x)=(x-mu)/sqrt(var+epsilon) * gamma + beta
PE(pos,2i)=sin(pos/100002i/d)
PE(pos,2i+1)=cos(...)

LayerNorm learns 2d parameters. Normalize across hidden features of one token.

Sampling

pi(tau)=exp(zi/tau) / sum exp(zj/tau)

Top-k keeps k tokens. Top-p keeps the smallest sorted prefix whose cumulative probability reaches p. Renormalize after truncation.

Tokenizer and scaling

WordPiece score(a,b)=count(ab)/[count(a)count(b)]
L(N,D)=[(8.8e13/N)0.8 + 5.4e13/D]0.095

BPE maximizes weighted adjacent-pair count. Unigram maximizes whole-segmentation probability.

Long context

Full: T2(2d-1) FLOPs for QKT
Score memory: BHT2b
KV cache: 2LHkvdhbT bytes

Local O(cTd); block O(T2d/n); Linformer O(kTd); Performer O(rTd).

Week 1

Transformer and multi-head attention

Q, K, V roles

  • Query: what this token seeks.
  • Key: how a token advertises itself.
  • Value: information returned if selected.
  • Self-attention: Q, K, V come from the same sequence through different learned projections.
  • Cross-attention: decoder supplies Q; encoder memory supplies K and V.

Multi-head shapes

  • dmodel=h dk in the standard equal-head setup.
  • Each head returns T x dv; concatenation returns T x h dv.
  • WO maps concatenated heads back to dmodel.
  • Head splitting changes intermediate shapes, not the standard total 4d2 projection count.

Exam traps

  • Scale by sqrt(dk), not sqrt(dmodel) unless they are equal.
  • Softmax is row-wise over candidate keys for each query.
  • Attention scores are activations, not trainable parameters.
  • State row-token or column-token convention before multiplying matrices.
Week 2

Decoder flow, masks, position, and normalization

Decoder dependency

  1. Shifted target embeddings plus position.
  2. Masked self-attention over the target prefix.
  3. Cross-attention to encoder outputs.
  4. Feed-forward network.

Each sublayer has residual addition and normalization under the course architecture.

Causal mask

Allowed pairs for length T = T(T+1)/2

Position i may attend to itself and earlier indices, never future indices. Teacher forcing supplies gold previous target tokens during training; the mask still enforces causality.

Position and normalization

  • Sinusoidal PE adds deterministic position features and supports relative offsets through trig identities.
  • BatchNorm uses batch statistics per feature.
  • LayerNorm uses hidden features per token and works with batch size 1.
  • Add position without increasing hidden width.

Recovery rule

For every decoder question, mark the source of Q, K, and V, mark which positions are visible, and only then calculate. A right-to-left language does not automatically require flipping the causal matrix; indices already encode the chosen sequence order.

Week 3

Causal language modelling and GPT

Training shift

Input [x1,...,x(T-1)] predicts [x2,...,xT] in parallel under a causal mask. Cross-entropy compares every valid prediction with its next-token target.

Exposure bias: training sees gold prefixes; inference sees the model's own outputs.

GPT signature

  • Decoder-only transformer blocks.
  • Masked self-attention, FFN, residuals, normalization.
  • No encoder-decoder cross-attention.
  • Pre-training starts from random parameters; fine-tuning starts from pre-trained parameters.

Parameter arithmetic

Attention per block: about 4d2
FFN per block: about 2d dff
Embeddings: Vd (+ position)

Always state whether token/output weights are tied and whether biases and LayerNorm parameters are included.

Do not confuse

Causality is an information-flow rule. Decoder-only is an architecture. CLM is an objective. Teacher forcing is a training input policy. They often appear together, but they are not synonyms.

Week 4

Decoding and BERT

Search methods

MethodRuleFailure or trade-off
ExhaustiveEnumerate all pathsExponential
GreedyBest next tokenLocal optimum
BeamKeep b best sequencesApproximate; length bias
Top-kSample from k highestFixed support size
Top-pSmallest mass-p prefixVariable support

BERT signature

  • Encoder-only and bidirectional.
  • MLM selects 15% positions: 80% [MASK], 10% random, 10% unchanged.
  • MLM loss is calculated on selected prediction positions.
  • NSP distinguishes consecutive from non-consecutive sentence pairs.
  • Input embedding = token + segment + position.

Architecture facts

  • BERT-base: 12 layers, 768 hidden, 12 heads.
  • BERT-large: 24 layers, 1024 hidden, 16 heads.
  • Token classification uses token states; sentence classification commonly uses [CLS].
  • Adaptation reuses pre-trained parameters.

Path and probability traps

In a decoding table, a conditional probability is valid only under its printed prefix. Multiply along one valid path. Beam width b is not top-k sampling k. Temperature changes sharpness but does not reorder fixed logits.

Week 5

Subword tokenization

BPE

  1. Start from characters and the supplied end-of-word convention.
  2. Count adjacent pairs using word frequency and within-word multiplicity.
  3. Merge the maximum-count pair.
  4. Add one vocabulary token, recompute, and store merge rank.
  5. Replay ordered ranks at inference.

WordPiece

score(a,b)=count(a,b)/[count(a)count(b)]

Merge the maximum normalized score, not necessarily the maximum raw count. Encoding uses greedy longest match with continuation markers such as ##.

Unigram and SentencePiece

  • Begin with a large seed vocabulary.
  • Assign piece probabilities.
  • Use Viterbi/dynamic programming for the most probable full segmentation.
  • EM-style pruning removes pieces with low contribution.
  • SentencePiece can operate without whitespace pre-tokenization.

Recurring traps

BPE pair count is not WordPiece score. A pair can occur twice inside one word and both occurrences are multiplied by word frequency. If WordPiece marginals are missing, the winning merge may be indeterminate. Vocabulary size increases by one per merge, not by two.

What GPT-2 demonstrated

  • Task behavior can be elicited through natural-language context without gradient updates.
  • Architecture, objective, dataset size/quality, and model scale are distinct experimental axes.
  • Zero-shot prompting is not fine-tuning.

Multitask and fine-tuning

  • Joint training needs an explicit task mixture.
  • Sampling can be balanced, proportional, or temperature-smoothed.
  • Fine-tune all parameters, selected layers, or task heads depending on data and compute.
  • Always identify architecture, mask, objective, I/O format, and task fit.
Week 8

Scaling, web data, cleaning, and mixtures

Scaling law discipline

L(N,D)=[(8.8e13/N)0.8 + 5.4e13/D]0.095

Compute each inner term, add, then apply the outer exponent. A larger N or D reduces the corresponding reducible component.

Common Crawl formats

  • WARC: raw response/archive content and HTML.
  • WAT: derived metadata.
  • WET: extracted plain text.
  • Extracted text is not automatically high-quality, safe, deduplicated training data.

Cleaning families

  • Language identification.
  • Rule or model-based quality filters.
  • Toxicity and bad-word filtering.
  • PII detection/redaction.
  • Exact dedup for equality; fuzzy/MinHash-style dedup for near copies.

Named pipelines

  • C4: English web text with heuristic line/document rejection and dedup.
  • CCNet: language ID plus Wikipedia-referenced LM quality bands.
  • Pile-CC: WARC, jusText, Pycld2.
  • SETU: OCR + ASR + scraping, producing Sangraha.

RefinedWeb order

URL -> extraction -> language -> repetition -> document filter -> line correction -> fuzzy dedup -> exact dedup

Percentages at successive stages multiply. Do not add removal rates from different populations.

Dataset traps

  • Quality, size, and diversity are different axes.
  • Mixture weights allocate training tokens; they do not alter raw corpora.
  • GA storage order: ROOTS > C4 > WebText > BookCorpus.
  • mC4, ROOTS, and Sangraha are multilingual; C4 is English.

Week 11

Efficient attention and fast inference

Method taxonomy

  • Local/sparse/block: remove edges; exact on retained edges.
  • Linformer: compress sequence axis to rank k.
  • Performer: approximate softmax kernel and reassociate.
  • FlashAttention: exact full attention with tiled/fused memory traffic.
  • KV cache: reuse past K/V in autoregressive decoding.

Pair counts

Full T2
Local cT
One-of-n block T2/n
Linformer Tk

Block permutations: n! valid permutations. A permutation uses every key block exactly once.

MQA and GQA

  • MHA: one K/V head per query head.
  • GQA: several query heads share each K/V group.
  • MQA: all query heads share one K and one V head.
  • Cache memory scales with Hkv, not Hq.

Complexity traps

Same Big-O does not imply the same representation. FlashAttention does not make arithmetic linear. Runtime score memory is not parameter count. Decimal KB/MB and binary KiB/MiB can produce different numeric options, so follow the printed convention.

Week 12

Relative position, RoPE, ALiBi, and NoPE

Position map

  • APE: add absolute vector at input.
  • Shaw RPE: add learned relative key/value terms.
  • T5: learned scalar relative score bias, often bucketed.
  • RoPE: rotate Q and K in paired dimensions.
  • ALiBi: add fixed head-specific linear distance bias to logits.
  • NoPE: rely on causal structure without explicit PE.

RoPE

R(m)TR(n)=R(n-m)

The rotated query-key dot product depends on relative offset. Embedding width must pair dimensions for 2D rotations.

ALiBi

score(i,j)=qiTkj/sqrt(d) - mh|i-j|

Different heads use different slopes. More distant keys receive a larger negative bias.

Extrapolation traps

  • Relative methods are not automatically identical.
  • NoPE does not mean delete trained positional embeddings at inference.
  • RoPE changes Q/K interaction; ALiBi changes logits.
  • Preserve the exact sign and distance convention supplied.
