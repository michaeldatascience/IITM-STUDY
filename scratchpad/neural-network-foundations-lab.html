Definitions remove noise

What exactly is the network?

Feedforward neural networkA collection of neurons organized in layers and connected as a directed acyclic graph. Information flows only from input toward output.
NeuronA vector-to-scalar function. It receives several numbers and returns one number.
LayerA group of neurons evaluated together. Its width nl is the number of neurons in that layer.
DepthThe number of layers excluding the input layer, using the official Week 3 convention.
ParameterA number learned from data. Here these are the entries of W and b.
HyperparameterA design choice made outside training, such as layer width or learning rate.
Pre-activation zThe affine evidence W a + b before the activation function acts.
Activation aThe value f(z) exposed to the next layer. This is a computed value, not a parameter.
Official forward notation

Read the superscript as location

The input is layer 1, so a(1) = x. The matrix W(l) maps layer l to layer l+1:

z(l+1) = W(l)a(l) + b(l)    and    a(l+1) = f(z(l+1))

The superscript is not an exponent. It identifies the layer. For matrix entries, this lab uses W(l)[j,i]: column i is the source neuron in layer l, and row j is the destination neuron in layer l+1.

The useful sentence: each row of W belongs to one destination neuron; each column receives one source activation.
Three different species

Do not call every number a parameter

Chosen by you

n1, n2, ..., activation type, and learning rate. These are architecture or training hyperparameters.

Learned from data

The entries inside W and b. These are trainable parameters.

Computed during a pass

z, a, h(x), L, δ, and gradients. These depend on data and parameters but are not themselves model parameters.

Shape laws

Rules worth retrieving

Destination by source

W(l) ∈ Rnl+1 × nl

The destination width gives rows. The source width gives columns.

One bias per destination

b(l) ∈ Rnl+1

The same bias vector is reused for every example in the batch.

Activation preserves width

z(l) and a(l) have the same shape

An element-wise activation changes values, not dimensions.

Gradient mirrors its variable

∇WL has the shape of W

You need one derivative for every learnable number.

Definition

Feedforward means evaluate left to right

For one input, compute each layer only after the previous activation is known. Nothing travels backward and there are no cycles. A three-layer network, counting the input layer, has one hidden layer and two learned affine maps.

x = a(1) → z(2) → a(2) → z(3) → a(3) = hW,b(x) → L
Why f matters: without a nonlinear activation, stacked affine layers collapse into one affine map. Depth would add parameters but not a new class of decision shape.

Interpretation

What the hidden layer actually did

The two rows of W(1) define two different evidence collectors. On this input, the first produced z = 3 and survived ReLU. The second produced z = -1 and was suppressed to 0. W(2) then mixed those two hidden features into the prediction.

The network is not moving through mysterious letters. It repeatedly performs: collect evidence → add a threshold shift → apply a decision shape.
Definition

Backpropagation is efficient differentiation

Backpropagation computes the gradient of the loss with respect to every learnable parameter by applying the chain rule through the computation graph from right to left. It is not an optimizer. Gradient descent uses the gradients that backpropagation produces.

Loss L←output error δ(3)←hidden error δ(2)←parameter gradients
δ(l) = ∂L/∂z(l)

Calling δ an error signal prevents a common confusion: δ is not the loss and not the prediction error alone. It is the derivative of the loss with respect to a layer's pre-activation.

Official vector form

The reusable algorithm

Output layer

δ(nl) = -(y-a(nl)) ⊙ f′(z(nl))

For half-squared error. Start where the loss directly touches the prediction.

Hidden layer

δ(l) = ((W(l))Tδ(l+1)) ⊙ f′(z(l))

Pull later error through transposed weights, then apply the local activation derivative.

Weight gradient

∇W(l)L = δ(l+1)(a(l))T

An outer product pairs every destination error with every source activation.

Bias gradient

∇b(l)L = δ(l+1)

A bias enters its destination pre-activation with local derivative 1.

Compression

Six-line cheat sheet

  1. Define the symbol before manipulating it.
  2. Forward: z(l+1) = W(l)a(l) + b(l), then a(l+1) = f(z(l+1)).
  3. Shape: W is destination × source; b has one value per destination.
  4. Parameters are entries of W and b. Activations and gradients are computed values.
  5. Backward: later error passes through WT, then through the local derivative f′.
  6. A gradient has the same shape as the variable it differentiates.
