Transformer Models — Aspect by Aspect

Eleven aspects, each with the intuition, the side-by-side, the trap, and the actual PYQ that hinges on it. Everything beyond Quiz 2 scope has been left out.

The one story — four students in an exam hall

Every model in this syllabus is a student sitting a different kind of test. Get these four pictures fixed and almost every question answers itself.

BERT

Cloze test. Sees the whole sentence with a few words blacked out. Fills in the blanks. Never writes new sentences.

GPT

Continue the story. Sees only what's written so far. Adds the next word. Cannot peek ahead — the rest isn't written yet.

BART

Retype this mess. Gets a mangled passage. Types out the entire clean version from scratch.

T5

Fill-in-the-blank worksheet. Blanks are numbered. Writes only the answers, each next to its number.

The master key Encoder = the reading brain. Decoder = the writing hand.
Everything follows from this. No decoder ⇒ cannot generate (BERT). No encoder ⇒ cannot look ahead (GPT). Both ⇒ reads one thing, writes another (BART, T5).

02Attention direction & masking

"Attention direction" means: which other tokens am I allowed to look at? There are only two directions in this syllabus.

DirectionMeansLives in
Bidirectionalsee everything — left, right, and yourself every encoder; BERT's whole model
Causal (forward-only)see yourself and everything before you; nothing ahead every decoder's self-attention; GPT's whole model
On "reverse" attention There is no reverse-only transformer in this syllabus. You may be thinking of older RNN models (ELMo) that ran one LSTM forward and one backward and glued them together. Transformers don't do that — bidirectional attention sees both directions at once in a single pass, which is a different and stronger thing. Only two directions exist here: bidirectional and causal.

Masking, region by region

WhereMasked?Why
Encoder self-attentionNo maskyou're reading a document that already exists — look anywhere
Decoder self-attentionCausal maskyou're writing; the future isn't written yet
Cross-attention (decoder → encoder)No maskthe input document is fully available while you write
Memory hook Reading is free, writing is blind. You can re-read a page in any order. But while writing a sentence, you cannot read the words you haven't written yet. That's the causal mask, and it's why GPT can never do MLM.

How the mask is actually applied

score → −∞ before softmax → e−∞ = 0 → attention weight exactly 0

It happens on the raw dot-product scores, before softmax. So a masked position gets weight exactly 0, not "a small number". You never need to compute exponentials for masked positions.

Prefix-LM — the dial between GPT and BERT

First p tokens see each other bidirectionally; everything after is causal.

T = 5, p = 2         1  2  3  4  5
            row 1 [  ✓  ✓  ✗  ✗  ✗ ]   ← can see token 2 (bidirectional inside prefix)
            row 2 [  ✓  ✓  ✗  ✗  ✗ ]
            row 3 [  ✓  ✓  ✓  ✗  ✗ ]   ← causal from here on
            row 4 [  ✓  ✓  ✓  ✓  ✗ ]
            row 5 [  ✓  ✓  ✓  ✓  ✓ ]        count = 16
non-−∞ count = T(T+1)/2 + p(p−1)/2

Sanity: p = 0 → pure causal (GPT). p = T → T², the full grid (BERT). Prefix-LM sits between them and p is the dial position.

03Pretraining objective

The objective is the game the model plays during pretraining. It's chosen to match what the architecture can physically do.

ObjectiveModelThe gameNeeds
MLM — Masked LMBERT black out ~15% of tokens, predict them from both sidesbidirectional attention
CLM — Causal LMGPT predict the next token from the left contextcausal mask
DenoisingBART corrupt the input, regenerate the whole originalencoder + decoder
Span corruptionT5 replace spans with sentinels, generate only the spansencoder + decoder
Prefix-LMUniLM read a prefix bidirectionally, then continue causallyhybrid mask
Trap — "which models use denoising?" BERT, BART, T5. Denoising means corrupt then reconstruct, and MLM counts — BERT corrupts by masking. GPT-3 does not: causal LM predicts the next token from clean text. Nothing is ever corrupted.

BERT's 80 / 10 / 10 rule

Of the 15% chosen for prediction: 80% become [MASK], 10% become a random word, 10% are left unchanged.

  • Why 10% unchanged? [MASK] never appears at fine-tuning time. If the model only ever built good representations at [MASK] positions, nothing would transfer. This is the pretrain / fine-tune mismatch.
  • Why 10% random? So the model can't blindly trust the token it sees — it has to keep checking against context.

05What the output looks like — the big one

This aspect alone separates BART from T5, which is the most-tested distinction in the whole topic.

ModelTarget / outputLength

The worksheet vs the retype

BART is told: "this passage is mangled — retype the whole thing correctly." It reproduces every word, including the ones that were never damaged.

T5 is told: "here's a worksheet with numbered blanks — write only the answers, each next to its number, then sign off." It never repeats the words that weren't blanked. The <Z> at the end is the sign-off, meaning "answer sheet finished."

That's why T5's targets are short — the entire computational argument for span corruption.

The binary rule that gets tested TARGET ends with [z] · INPUT does not.
Why: the input already has an end — the rest of the sentence follows the last sentinel. The output doesn't; the decoder needs a stop signal.
Trap — the naming twin Sentinel letters are arbitrary. [v][w][x][y][z] and [a][b][c][d][z] are both correct. Only three things are graded: spans in original order, distinct sentinels, and the terminal [z]. These appear as multiple-select questions with two right answers. Picking only the natural-looking one scores half.
PYQ 2025T3 Q122: corrupted The quick <X> fox <Y> over the lazy dog → target <X> brown <Y> jumps <Z>. Not "brown jumps" (no sentinels), not the full sentence (that's BART).
2025T3 Q118: model C outputs "cat … the" bare → BART; model D outputs sentinel-prefixed fragments → T5.

06What feeds the decoder during training

Only relevant for BART and T5 — the other two have no decoder.

decoder input = the target sequence, shifted right by one

This is teacher forcing: at step t, the decoder is shown the correct tokens 1…t−1, not its own guesses. Otherwise one early mistake would poison everything after it and training would never get off the ground.

Encoder receivesDecoder receives
BARTthe corrupted textthe original uncorrupted text, shifted right
T5the sentinel-substituted textthe target (sentinels + spans), shifted right
Trap The corrupted text goes to the encoder, never the decoder. "The decoder receives the corrupted text from the encoder" is the standard wrong option — it sounds plausible because the encoder did read the corrupted text, but what passes to the decoder is the encoder's hidden states via cross-attention, not the raw corrupted tokens.
PYQ 2025T3 Q124: what is fed to BART's decoder during denoising pretraining? → the original, uncorrupted text, shifted right by one token.

07Loss — same formula, different positions

Every model here uses cross-entropy over the vocabulary. The formula never changes:

L = −(1/n) Σt ln p(correct token at step t)

where: n = number of positions being scored; p(correct token) = the probability the model put on the right word, read from that position's distribution.

ModelLoss computed atn =
BERTonly the masked positions~15% of tokens
GPTevery position (each predicts the next)sequence length
BARTevery decoder positionlength of the full original
T5every decoder positionlength of the span-target (short)
Trap — the 4-mark one MEAN, not sum. And read the correct token's probability, not the row maximum.

"Greedy decoding" in the question describes how the matrix was produced — it is not an instruction to take maxima. Loss measures wrongness, so it must look at the right answer. A model that confidently generates nonsense would score a low loss under the max reading, which is backwards.

GA7: sum = 7.62, correct answer = 1.09.
PYQ procedure 1. Number the vocabulary columns in the order V is written. 2. Write the target sequence = the original sentence, minus [start], one word per row. 3. Read each row at that word's column. 4. Negative natural logs, then average.

T5's contract, and why it forbids things

T5's rule is: every task is text in → text out. Nothing is ever bolted onto the model.

  • Classification: label 0 becomes the string "negative" — or the string "0". Both are valid.
  • Regression: STS-B similarity 3.8 is generated as the literal characters "3.8", token by token, by the decoder.
  • No vocabulary update needed — those label strings tokenize fine with the existing vocabulary.
  • No difference between pretraining and fine-tuning objective — both are sequence generation. That uniformity is exactly what lets one checkpoint serve every task.
Two traps in one question (1) "Add a linear layer on top of the decoder for classification" is always wrong for T5.
(2) The label mapping must cover every class. With three classes, a mapping that only handles 0 and 1 silently drops class 2 — wrong, even though it looks reasonable.
And as usual, two options are correct: the word mapping and the digit-string mapping.

The two compute facts that get asked

  • Shared encoder-decoder halves the parameters. A 220M model with equal halves, sharing WEnc = WDec, becomes 110M.
  • Decoder(P) and Encoder-Decoder(2P) cost the same — TRUE. In the enc-dec, the input sequence passes only through the P encoder parameters and the output only through the P decoder parameters. Each token traverses ~P, not 2P. This is T5's central argument that enc-dec is not "twice as expensive".
Memory hook Two rooms, one corridor. The encoder and decoder are separate rooms. A given token only ever walks through one of them — the input goes to the reading room, the output to the writing room. So doubling the total floor space doesn't double any individual token's walk.

✎Practice — answer before unfolding

A model is given "The cat sat on the __" and must predict "mat" using both left and right context. Which model, and could GPT do this?2025T3 Q118 · 2026 Q4

BERT. "Both left and right context" is the definition of MLM, which requires bidirectional attention.

GPT cannot. Its causal mask blocks attention to future tokens, so the right-side context is physically unreachable. The objective and the mask are structurally incompatible — not a matter of model size or activation function.

Model C: given "The <X> sat on <Y> mat", generates "cat … the". Model D: given "<extra_id_0> cat sat <extra_id_1> mat", generates "<extra_id_0> The <extra_id_1> on the". Which is BART, which is T5?2025T3 Q118

C = BART, D = T5.

Look at the output, not the input — both inputs have placeholders. C emits bare words; D emits sentinel-prefixed fragments. Sentinels in the output ⇒ T5, always.

Which models use a form of denoising objective: BERT, GPT-3, BART, T5?Mar25 Q9

BERT, BART, T5.

Denoising = corrupt then reconstruct. BERT masks tokens (MLM is a denoising objective). BART corrupts and rebuilds the whole sequence. T5 corrupts spans and emits only the spans.

GPT-3 is not. Causal LM predicts the next token from clean text — nothing is corrupted, so there is nothing to denoise.

Which components are found in a standard Transformer Encoder layer?2026 Q8

Multi-head self-attention and position-wise feed-forward network.

Not cross-attention — that connects a decoder to an encoder, so it lives in the decoder. Not masked self-attention — also decoder-only; the encoder is bidirectional by definition. Both wrong options are decoder parts smuggled into an encoder question.

In an encoder-decoder Transformer, where do Q, K, V come from in the decoder's cross-attention?2025T3 Q128

Q from the decoder's previous sub-layer; K and V from the encoder's final hidden states.

Mnemonic: the decoder is the one asking (query). The encoder holds the content being looked up (key/value). You bring your question to the library; the library holds the books.

An attention mask lets A and B see each other, and lets D see A, B, C but not E. Which objective?2025T3 Q123

Prefix Language Modeling.

Bidirectional block at the front (A ↔ B), causal afterwards (D sees back but not forward). CLM would forbid A from seeing B. MLM would let D see E. BART's denoising is described by an architecture, not by one mask over one sequence.

A company needs sentiment classification: 10,000 reviews/min, memory-constrained, no explanations. BERT or BART?2025T3 Q120

BERT — classification requires understanding (encoding), not generation (decoding), so it is faster and more memory-efficient without sacrificing accuracy.

Carrying a decoder you never invoke is pure cost. The tempting distractor — "use BART's encoder only and discard the decoder" — just reinvents a worse BERT, since BART's encoder wasn't pretrained for that role.

What is the fundamental difference between T5's pretraining objective and its supervised fine-tuning objectives?2025T3 Q121

There is no fundamental difference — both are text-to-text tasks generating a target sequence from an input sequence.

Same architecture, same decoder, same cross-entropy loss. That uniformity is precisely what lets one checkpoint serve every task with no architectural change.

▣Model Cards — architecture in detail

Each card: the diagram, the layer-by-layer breakdown, the configuration numbers that actually get tested, and what the exam asks. Everything beyond Quiz 2 scope is left out.

Card 0 — the shared skeleton

All four models are built from the same repeating block. What changes is (a) which sub-layers are inside it, and (b) whether the attention is masked. Learn the block once.

Read the difference: the only thing separating the three is the attention row. Encoder = unmasked self-attention. Decoder-only = masked self-attention. Encoder-decoder's decoder = masked self-attention plus a cross-attention sub-layer that reaches into the encoder.

What gets asked about the block 2026 Q8 — components of an encoder layer: multi-head self-attention + position-wise feed-forward. Cross-attention and masked self-attention are decoder parts smuggled into an encoder question.

LayerNorm parameters: each "Add & Norm" learns γ and β, one per feature ⇒ 2H. For 512 features that's 1024. BatchNorm also has 2H — the difference is what they average over, not how many parameters they hold.

Prefix-LM — the dial between GPT and BERT

Not a separate architecture so much as a masking scheme. One stack, one sequence: the first p tokens attend bidirectionally among themselves; everything after is causal. T5 studied it as an alternative objective; UniLM is the named model.

Read the three grids together The middle grid is the left grid's top-left corner pasted onto the right grid. That's literally all Prefix-LM is — and it's why p = 0 gives GPT and p = T gives BERT. If your formula doesn't degrade correctly at both ends, you've derived it wrong.
