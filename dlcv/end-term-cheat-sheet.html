Week 1

Images, filters, frequency, and sampling

Correlation and convolution

  • Correlation slides the kernel as stored.
  • Convolution flips it horizontally and vertically before sliding.
  • Padding controls border support; stride controls sampling of output positions.
  • A separable K x K filter costs about 2K multiplications per output instead of K2.

Filter signatures

  • Average/Gaussian: low-pass smoothing.
  • Median: nonlinear and effective for impulse noise.
  • Derivative/Sobel: high-pass directional change.
  • Laplacian: second derivative; LoG combines smoothing and Laplacian response.
  • Integral image gives rectangle sums with four references.

Frequency and sampling

  • Spatial convolution corresponds to frequency-domain multiplication.
  • Low frequencies encode slow variation; high frequencies encode edges/detail.
  • Sampling below the Nyquist requirement creates aliasing.
  • Anti-alias filtering removes high frequencies before downsampling.

Arithmetic traps

Read whether the operation is valid, same, or full. Do not flip a kernel twice. Operation counts depend on whether additions, multiplications, boundaries, and separability are included. Preserve the convention printed in the question.

Week 2

Edges, corners, scale space, SIFT, and segmentation

Canny order

  1. Gaussian smoothing.
  2. Gradient magnitude and direction.
  3. Non-maximum suppression.
  4. Double threshold.
  5. Hysteresis edge linking.

Non-maximum suppression thins along the gradient direction.

Second moment matrix

M=sum w(x,y)[Ix2 IxIy; IxIy Iy2]
R=det(M)-k trace(M)2

Both eigenvalues small: flat. One large: edge. Both large: corner.

Scale and SIFT

  • Gaussian scale space handles structures at different sizes.
  • DoG approximates LoG for scale-space extrema.
  • SIFT: detect extrema, localize/reject unstable points, assign orientation, build histogram descriptor.
  • Orientation gives rotation robustness; scale selection gives scale robustness.

Recognition depth

  • Image pyramids reduce resolution across levels.
  • Filter banks capture multiple orientations/scales.
  • Segmentation groups pixels/regions, unlike sparse keypoint detection.
  • Feature detector repeatability matters under viewpoint and illumination changes.
Week 3

Neural networks, backprop, optimization, and regularization

Forward and loss

z=WTx+b, a=phi(z)
softmax(zi)=ez_i/sum ez_j
CE=-sum yilog pi

Softmax is unchanged by adding one constant to every logit.

Derivatives

  • Backprop applies the chain rule from loss to parameters.
  • Shared-use gradient contributions add.
  • ReLU derivative is 1 for positive input and 0 for negative input.
  • Sigmoid derivative is sigma(1-sigma); saturation causes small gradients.

Optimizers

  • SGD uses the current gradient.
  • Momentum accumulates a velocity direction.
  • Adagrad accumulates squared gradients and can decay too aggressively.
  • RMSProp uses an exponential squared-gradient average.
  • Adam combines first and second moments with bias correction.

Training discipline

  • Xavier suits tanh-like activations; He suits ReLU-like activations.
  • L2 shrinks weights; L1 promotes sparsity.
  • Dropout is active during training and scaled/disabled appropriately at inference.
  • Validation chooses hyperparameters; test estimates final generalization.
Week 4

CNN mechanics, backprop, AlexNet, and VGG

Shape/count routine

  1. Compute effective kernel with dilation.
  2. Apply floor output formula separately to H and W.
  3. Count weights plus one bias per output channel when included.
  4. Compute MACs using output positions.
  5. Trace receptive field and effective jump layer by layer.

Backprop shapes

  • Gradient w.r.t. weights has the same shape as weights.
  • Gradient w.r.t. input has the same shape as input.
  • Weight sharing means gradients sum over every spatial use.
  • Pooling changes gradient routing but adds no learned parameters.

Architecture signatures

  • AlexNet: early large kernels/strides, ReLU, dropout, GPU-era breakthrough.
  • VGG: repeated small 3 x 3 convolutions and deeper uniform stacks.
  • Two 3 x 3 stride-1 convolutions give 5 x 5 receptive field with extra nonlinearities.

Known weak-area ledger

Padding changes output shape, not learned weight count. Sequence length/spatial size changes activations and MACs, not kernel parameters. Pooling expands receptive field. Use floor, not rounding. Historical GA4 performance makes this block a compulsory handwritten derivation.

Week 5

Modern CNNs, efficient convolution, transfer, and visualization

Architecture map

  • Inception: parallel branches with different receptive fields and 1 x 1 bottlenecks.
  • ResNet: identity skip plus learned residual F(x).
  • DenseNet: each layer receives earlier feature maps by concatenation.
  • EfficientNet: coordinated depth, width, and resolution scaling.

Depthwise separable

Standard: K2CinCout
Depthwise + pointwise: K2Cin + CinCout

Depthwise filters each channel independently; 1 x 1 pointwise convolution mixes channels.

Transfer learning

  • Freeze features for small similar datasets.
  • Fine-tune later layers when the target differs or more data is available.
  • Use a smaller learning rate for pre-trained weights.
  • Replace the task head to match target labels.

Visualization

  • Occlusion measures prediction change when regions are hidden.
  • CAM requires GAP plus a compatible linear class head.
  • Grad-CAM weights feature maps using class-gradient averages.
  • Saliency gradients identify sensitive input pixels, not causal proof.
Week 6

Detection, metrics, and segmentation

Detector lineage

  • R-CNN: external proposals, per-region CNN.
  • Fast R-CNN: shared feature map, per-ROI features.
  • Faster R-CNN: learned Region Proposal Network.
  • YOLO/SSD: single-stage dense prediction.
  • FPN: top-down multi-scale feature pyramid.

Anchors and losses

  • Anchors vary location, scale, and aspect ratio.
  • Classification applies to candidates; box regression is gated to foreground/positive anchors.
  • Focal loss downweights easy examples under class imbalance.
  • Box deltas are relative to anchor geometry.

NMS and AP

  1. Sort by confidence.
  2. Keep highest remaining box.
  3. Suppress lower boxes above IoU threshold.
  4. Repeat.

Interpolated precision at recall r is the maximum precision observed for recall at least r.

Segmentation map

  • Semantic: class per pixel.
  • Instance: separate mask per object.
  • Panoptic: semantic + instance coverage.
  • U-Net: encoder-decoder with skip features.
  • Mask R-CNN: Faster R-CNN plus a parallel mask branch.

Metric relation

Dice = 2IoU/(1+IoU)
IoU = Dice/(2-Dice)

mAP averages AP over classes and, depending on the stated convention, possibly multiple IoU thresholds.

Do not conflate

IoU evaluates overlap; NMS removes duplicates; AP integrates a ranked precision-recall curve. They occur in one detector workflow but answer different questions.

Week 7

RNNs, BPTT, gates, and video understanding

Vanilla recurrence

ht=phi(Wxhxt+Whhht-1+b)
yt=Whyht+c

Parameters are shared over time. Longer sequences add computation and saved activations, not new weights.

BPTT and gradient health

  • Unroll the shared recurrence, then apply ordinary backprop.
  • Repeated Jacobian products can vanish or explode.
  • Gradient clipping addresses explosion.
  • LSTM/GRU gates create more stable memory routes.

Gate map

  • LSTM forget gate retains old cell state.
  • Input gate controls candidate writing.
  • Output gate exposes cell memory as hidden state.
  • GRU update gate mixes old state and candidate; reset gate controls candidate history use.

Video models

  • Frame CNN + temporal pooling: simple but weak order modelling.
  • 3D CNN: joint space-time kernels.
  • Two-stream: RGB appearance + optical-flow motion.
  • LRCN: CNN frame features followed by an RNN/LSTM.

Historical weak area

Count one shared cell, not one cell per time step. Separate recurrent-cell parameters from output-head parameters. In gate diagrams, identify the path carrying the old memory before naming the gate.

Week 8

Visual attention, captioning, VQA, and transformers

Soft spatial attention

eti=score(ht-1,ai)
alphati=softmaxi(eti)
zt=sum alphatiai

Differentiable weighted averaging supports ordinary backprop.

Soft vs hard

  • Soft: attend to all locations with continuous weights.
  • Hard: sample/select discrete locations and may need stochastic-gradient estimators.
  • Temperature below 1 sharpens a softmax; above 1 flattens it.

Applications

  • Captioning aligns generated words with image regions.
  • VQA fuses image evidence with a question representation.
  • Visual dialog adds conversation history and answer context.
  • Self-attention creates pairwise interactions among visual tokens/regions.

Counting trap

M visual tokens create M2 self-attention score entries per head. Do not call these parameters. For cross-attention, use TqueryTkey, not automatically T2.

Week 9

Vision transformers, DETR, segmentation, and SAM

ViT path

image -> non-overlapping patches -> flatten/project -> position (+ class token) -> transformer encoder -> task head

Patch projection maps P2C raw values to dmodel. A plain ViT is isotropic across blocks.

Swin

  • Window attention limits each token to an M x M window.
  • Shifted windows connect neighboring windows across blocks.
  • Patch merging builds a hierarchy with lower resolution and more channels.
  • Window score count is M2HW.

DETR family

  • CNN features + position -> encoder.
  • Learned object queries -> decoder.
  • Each query predicts class/no-object and a box.
  • Hungarian one-to-one matching creates a set loss and removes standard NMS.
  • Deformable DETR samples K points instead of all HW locations.

Segmentation transformers

  • Transformer encoders can provide global context for dense prediction.
  • MaskFormer-style methods cast segmentation as mask classification.
  • SAM combines an image encoder, prompt encoder, and mask decoder.
  • SAM data engine: assisted-manual -> semi-automatic -> fully automatic.

Known weak-area ledger

Patch count is (H/P)(W/P), not H/P + W/P. Add class/distillation tokens only when the architecture states them. ViT has less built-in locality than a CNN. DETR matching is global one-to-one assignment, not greedy nearest-box selection.

Week 10

GANs, VAEs, and disentanglement

GAN objective

minG maxD Edata[log D(x)] + Ez[log(1-D(G(z)))]

For fixed G, D*(x)=pdata/(pdata+pg). At pdata=pg, D*=1/2.

GAN practice map

  • Alternate discriminator and generator updates.
  • Non-saturating generator loss improves early gradients.
  • DCGAN uses convolutional architectural constraints.
  • Mode collapse: generator covers too few modes.
  • FID compares Gaussian statistics in feature space; lower is better.

VAE ELBO

ELBO = Eq(z|x)[log p(x|z)] - KL(q(z|x)||p(z))
KL diagonal Gaussian = 0.5 sum(mu2+sigma2-log sigma2-1)

Reconstruction fits data; KL regularizes the approximate posterior toward the prior.

Latent variables

  • Encoder outputs mu and scale/log-variance.
  • Sample epsilon independently from N(0,I), then reparameterize.
  • Decoder maps z to a data distribution.
  • beta-VAE increases KL weight to encourage factorized latents, trading reconstruction.

Do not conflate

GANs are implicit adversarial samplers; VAEs optimize a likelihood lower bound with explicit latent regularization. z=mu+sigma epsilon uses standard deviation, not variance, unless the network output is transformed accordingly.

Week 11

Diffusion models, DDPMs, and guidance

Forward process

q(xt|xt-1)=N(sqrt(1-betat)xt-1, betatI)
alphat=1-betat, alpha_bart=product alphas

The forward process is fixed and gradually adds Gaussian noise.

Direct noising and training

xt=sqrt(alpha_bart)x0+sqrt(1-alpha_bart)epsilon
Lsimple=E||epsilon-epsilontheta(xt,t)||2

The model commonly predicts the injected noise; sampling iteratively denoises.

Guidance

  • Classifier guidance uses gradients from a separate noisy-image classifier.
  • Classifier-free guidance trains conditional and unconditional behavior in one model by dropping conditions.
  • Increasing guidance usually improves condition fidelity but can reduce diversity.

CFG convention

epsilon_hat = epsilonu + gamma(epsilonc-epsilonu)

gamma=0 gives unconditional; gamma=1 gives conditional; gamma>1 extrapolates.

Schedule traps

beta is per-step noise variance; alpha is retained signal per step; alpha_bar is cumulative retained signal. Large t means less x0 signal. Keep bar notation visible throughout arithmetic.

Week 12

Contrastive learning and vision-language models

Metric learning

  • Course pairwise convention: y=0 similar, y=1 dissimilar.
  • Triplet needs dap2+alpha < dan2.
  • Hard positives are far; hard negatives are close.
  • Semi-hard negatives are farther than the positive but still violate the margin.

SimCLR

2N views; 1 positive and 2(N-1) negatives per anchor
InfoNCE=-log exp(sim+/tau) / sum exp(sim/tau)

Augment -> shared encoder -> projection head -> normalized contrastive objective. Smaller tau sharpens similarity differences.

CLIP

  • Separate image and text encoders.
  • Normalize embeddings, construct batch similarity matrix.
  • Symmetric image-to-text and text-to-image contrastive losses.
  • Zero-shot classification compares an image with prompted class texts.
  • Cosine equals dot product only after unit normalization.

Beyond CLIP

  • BLIP: image-text contrastive, image-text matching, and language modelling.
  • BLIP-2: frozen image encoder + Q-Former + frozen LLM.
  • Q-Former mask routes unimodal contrastive, bidirectional matching, or causal generation behavior.
  • CoCa combines contrastive and captioning losses.
  • LLaVA connects a vision encoder to an LLM, then instruction-tunes multimodal data.

VQ-VAE and latent diffusion bridge

  • VQ-VAE selects the nearest codebook vector.
  • Straight-through estimation carries gradients around discrete choice.
  • Latent diffusion applies diffusion in a compressed autoencoder latent space.

Recurring traps

  • State positive-pair definition before writing a loss.
  • Do not silently replace the course contrastive-loss convention.
  • CLIP aligns global embeddings; BLIP adds fusion and generation.
  • BLIP-2 freezes both large backbones in the central setup.
