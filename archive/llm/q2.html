B2Highest / lowest frequency pair the only card needing a full tally
Which of the following pairs has the highest frequency before any merge?
('u','g') · ('a','u') · ('g','h') · ('h','t') · ('w','e') · None
Direction
  1. A word of n symbols gives n−1 pairs — including the one ending in </w>.
  2. Every pair contributes the word's frequency, not 1. Add the same pair across words.
  3. It's an MCQ — score only the options, not all 25 pairs. That's the time-saver.
  4. Check whether the max is tied before answering.
Answer & theory
freq(a,b) = Σwords (count of word) × (times (a,b) is adjacent in it)

Word frequency is never compared to anything — it only gets multiplied in when tallying a pair. Words don't compete; pairs do.

('u','g'): 2 + 1 + 4 + 5 = 12
('g','h'): 2 + 1 + 4 + 5 = 12   ← tie
('a','u'): 2 + 1         = 3
('h','t'): 2 + 1 + 4     = 7
('w','e'): no 'w' at all = 0

Tie-break: scan words in the order given, left to right. In t-a-u-g-h-t-</w> the pairs come as (t,a), (a,u), (u,g), (g,h)… → ('u','g').

Ties are the norm. Dec24: three pairs at 18. Aug25: two at 12. GA5: three at 21. Never grab the first max you spot.

Checksum to catch a dropped pair

Total pair slots = Σ (word count × word length). For this corpus 2·6 + 1·8 + 4·7 + 5·5 = 73. If your tally doesn't sum to that, you missed one — usually the </w> pair.

Lowest-frequency variants

deeper/keener/sweeter → ('p','e') = 5 · gentler/brighter/crisper → ('p','e') = 3 · low/older/finest/… → ('w','</w>') = 4.

W1WordPiece score, first merge, and encoding Aug25 Q18 · 2025T3 Q107–109, Q125 · GA5 Q11–12
Corpus {gentler:4, brighter:5, crisper:3}, </w> appended. Which pair is merged first under score = count(α,β) / (count(α)·count(β))?
A. ('e','r')   B. ('r','</w>')   C. ('b','r')   D. ('r','i')
Direction
  1. You need two tallies: adjacent-pair counts (as in BPE) and how often each character appears anywhere, both weighted by word frequency.
  2. Score only the options.
  3. If options tie, use the same first-occurrence tie-break as BPE.
Answer & theory

Why the denominator exists

BPE merges pairs that are frequent because their halves are individually frequent. WordPiece asks the sharper question: does this pair co-occur more than chance predicts? Dividing by count(α)·count(β) penalises pairs built from very common characters.

character counts (weighted):

paircount(αβ)denominatorscore
('e','r')1216 × 20 = 3200.0375
('r','</w>')1220 × 12 = 2400.0500
('b','r')55 × 20 = 1000.0500
('r','i')820 × 8 = 1600.0500

Three-way tie at 0.05. First occurrence: ('r','</w>') is in gentler (word 1) → Option B.

('e','r') ties on raw count (12) and still loses. BPE would have merged it — it's the joint winner there. WordPiece rejects it because e is common (16). That divergence is the entire point.

Also: the true global winner here is ('s','p') at 0.333 — not an option. Score the options only.

score = 6/(6×14) = 1/14 = 0.0714  →  100·s = 7.14

First piece has no ##; every later piece is looked up with ##. Take the longest match at each position and move on.

U1Unigram / Viterbi best segmentation Aug25 Q7
Input peanutbutter. Log-probs: pea −1.0, nut −0.8, but −1.2, ter −0.7, butter −1.0, peanut −0.5, t −2.0, er −1.5. Most probable tokenization?
A. [peanut,but,ter]   B. [pea,nut,butter]   C. [peanut,butter]   D. [pea,nut,but,ter]
Direction Log-probabilities add. All four candidates are given, so just sum each and pick the least negative. Build the DP table only if no options are offered.
Answer & theory
log P(s₁…sk) = Σ log p(si)  ·  best[i] = maxj<i ( best[j] + log p(x[j:i]) )

Pieces are independent, so the objective decomposes into a plain sum — which is what makes dynamic programming exact.

[peanut, butter]      −0.5 −1.0            = −1.5  ← highest
[peanut, but, ter]    −0.5 −1.2 −0.7       = −2.4
[pea, nut, butter]    −1.0 −0.8 −1.0       = −2.8
[pea, nut, but, ter]  −1.0 −0.8 −1.2 −0.7  = −3.7          Option C

Where Unigram sits: BPE and WordPiece are greedy and constructive — build up merges, never undo. Unigram starts with a large candidate set and prunes pieces whose removal costs least likelihood. SentencePiece is not a fourth algorithm — it's a framework wrapping BPE or Unigram that reads raw text as a stream (no whitespace splitting, so it works for Japanese) and encodes spaces as ▁ so detokenization is lossless.

Sentinel tokens & objectives 2 cards

S1Sentinel sequence — target vs input Dec24 Q13 · Mar25 Q7 · 2025T3 Q122 · GA7 Q3
Strikeout words are dropped from the original sentence. Some papers ask for the correct target sequence; others ask for the correct input. Options differ only in (i) sentinel naming — [a][b][c] vs [v][w][x], (ii) whether it ends with [z], (iii) span order.
Direction Read which is asked. Then apply one binary rule about the terminal [z]. Then check the option list for a naming twin — these are multiple-select and both naming schemes are usually correct.
Answer & theory

The fill-in-the-blank worksheet analogy

The input is the question paper: blanks numbered in place. The target is the answer sheet: blank number, then what went in it, and nothing else. The answer sheet never repeats the words that weren't blanked.

Original: The cat sat on the warm mat        drop: "cat sat" and "warm"

INPUT :  The <X> on the <Y> mat            ← no terminal sentinel
TARGET:  <X> cat sat <Y> warm <Z>          ← ends with terminal sentinel
TARGET ends with [z] · INPUT does not

Why? The input already has an end — the rest of the sentence follows it. The output doesn't; the decoder needs a stop signal. Sentinel naming is free; only order and the terminal sentinel are graded. One sentinel replaces a whole span, however many words.

D1BART greedy-decoding loss Mar25 Q12 · GA7 Q1 — 4 marks
Vocabulary V = ([start], deep, hot, is, learning, research, topic, very, [end]). Original sentence "[start] deep learning is very hot research topic [end]", corrupted "[start] deep [mask] is [mask] very hot [mask] topic [end]". An 8×9 matrix Ŷ is given, row 0 being the distribution after [start]. What is the loss value?
Direction
  1. Number the vocabulary columns in the order V is written.
  2. Write the target sequence — the original uncorrupted sentence, one token per row.
  3. Read off the probability in each row's gold token column.
  4. Negative natural logs. Then be very careful about the last operation — sum, or mean?
Answer & theory
L = −(1/n) Σt=1n ln p(goldt)

where: n = number of prediction steps (rows); ln = natural log; goldt = the token the model was supposed to produce at step t.

MEAN, not sum. The single most expensive error in the syllabus — off by a factor of n. In GA7 the sum was 7.62 and the answer was 1.09; a submission of 7.6 scored zero on a 4-mark question.

Important implication of the scaling law?Dec24 Q16 · Aug25 Q3

Both the size of the model and that of the data have to be increased appropriately to improve test performance.

Growing one alone hits a wall set by the other. Always false: "training longer always helps", "larger models require less data", "model size alone, irrespective of data".

Given 4× more compute, what is the best way to use it?Aug25 Q8

Increase model size by ≈2× and training data by ≈2×.

Compute C ≈ 6ND, and optimal scaling grows N and D roughly equally, so a 4× budget splits as 2× and 2×. Wrong: 4× on either one alone, or doubling model size while halving data.

Which loss does L(N, D) represent — training, in-distribution test, or out-of-distribution test?2025T3 Q119

Test loss on the same distribution as training — option 2 only.

The scaling law is fitted to held-out loss on the same data distribution. It says nothing about training loss (which can be driven lower by memorisation) and nothing about transfer to a different distribution.

Identify the correct scaling-law formula.GA8 Q5

L(N,D) = [ (Nc/N)αN/αD + Dc/D ]αD

Two checks, in this order: (i) the N term carries exponent α_N/α_D — options that flip it to α_D/α_N are wrong; (ii) the outer exponent is α_D — options using α_N are wrong. Nothing else distinguishes the four options.

Decoding & normalization
Which decoding method gives the same response every time for a given prompt?2025T3 Q115

Beam Search with beam-size 5 and Beam Search with beam-size 1.

Beam search (including width 1, which is greedy) does no sampling anywhere. All top-k and top-p options are non-deterministic regardless of k, p, or temperature — temperature reshapes the distribution but never removes the random draw.

For a layer with 512 features, how many learnable parameters do BatchNorm and LayerNorm have?2025T3 Q127

BatchNorm: 1024, LayerNorm: 1024.

Each learns a scale γ and a shift β, one per feature ⇒ 2H either way. The difference between them is what they average over (batch vs features), not how many parameters they have. Options that give them different counts are testing whether you've confused "what it normalises across" with "how many parameters it holds".

What is the dimension of the concatenated output of h heads before WO?2026 Q2

T × 512 (for d_model = 512, h = 8).
