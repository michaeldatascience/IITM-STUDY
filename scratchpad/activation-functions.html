Activation Functions and Derivatives

An activation function decides how strongly a neuron passes its pre-activation forward. Its derivative decides how strongly learning pressure passes backward.

The central idea

Why take the derivative?

A neuron first computes a pre-activation z, then outputs a = f(z). During backpropagation, the chain rule multiplies the incoming learning signal by f′(z):

∂L/∂z = ∂L/∂a × f′(z)

Think of f′(z) as a gradient valve. Near zero, it blocks learning at that neuron. Near one, it passes most of the signal. Very large repeated factors can amplify the signal. This is why the forward shape and derivative shape both matter.

Softplus at zero

softplus(0) = ln 2 ≈ 0.693softplus′(0) = σ(0) = 0.5

This is a recurring course-style derivative calculation. The function value and derivative value are different numbers.

Softmax is not sigmoid

Sigmoid treats each logit as an independent binary gate. Softmax makes the outputs compete because their probabilities must sum to 1. Its derivative is therefore a Jacobian matrix with cross-effects.

ReLU versus Leaky ReLU

For x = −3, ReLU outputs 0 and sends gradient 0. With α = 0.01, Leaky ReLU outputs −0.03 and sends 1% of the incoming gradient.

Common traps

Do not claim that ReLU is differentiable at 0. Do not give Softplus the range [0,∞), because it approaches 0 but never reaches it. Do not differentiate Softmax as if each output were independent.

Course boundary

What belongs here?

The DLCV Quiz 1 activation exercise explicitly includes Linear and Indicator along with Leaky ReLU and Softplus. Linear has constant derivative 1. Indicator is discontinuous at its threshold and has zero derivative away from it, so it is unsuitable for ordinary gradient-based hidden-layer learning.

Later LLM material also names GELU, ELU, Swish, SwiGLU, and GeGLU. Those belong with the corresponding architecture or feed-forward-block lesson. They are not silently folded into this foundation note.

Resistance check

Answer before revealing

1. A ReLU unit receives x = −4. What are its output and local derivative?
Output 0; local derivative 0. The incoming gradient is blocked at this unit.
2. With Leaky ReLU α = 0.01 and x = −4, what changes?
Output −0.04; local derivative 0.01. A small learning signal can still pass backward.
3. Why is the maximum sigmoid derivative 0.25?
σ′ = σ(1 − σ). This product is largest when σ = 0.5, which occurs at x = 0, giving 0.5 × 0.5 = 0.25.
4. Softmax probabilities are [0.7, 0.2, 0.1]. What is ∂p₁/∂z₁?
p₁(1 − p₁) = 0.7 × 0.3 = 0.21. For a different logit, such as z₂, the derivative would be −p₁p₂ = −0.14.
5. Which function is smooth, has range (0,∞), and has sigmoid as its derivative?
Softplus: ln(1 + eˣ).
