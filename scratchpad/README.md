# Concept Scratchpad

This folder is the durable registry for small reviewed concept notes and reusable interactive artifacts that arise during study or discussion.

## Before creating something new

1. Search `catalog.json` by title and tags.
2. Reuse the existing artifact if it already explains the mechanism.
3. Improve the existing artifact when the new work is an extension, not a genuinely different learning tool.
4. Create a new entry only when it adds a distinct explanation, visualization, or mode of practice.

## Publication contract

- Publish reviewed HTML only. Raw Markdown remains authoring material and is not linked from the hub.
- Preserve official course nomenclature, notation, examples, and boundaries.
- Connect the concept to PYQ, GA, or PA patterns when relevant.
- Add prediction-first questions or resistance prompts wherever useful.
- Link the canonical parent volume when one exists.
- Use relative paths and static assets so every page works on GitHub Pages.
- Add every reusable page to `catalog.json` and verify its link before publishing.

## Entry types

- **Quick concept:** a focused explanation that began in a chat but is worth retaining.
- **Interactive lab:** a dedicated visual or numerical tool for manipulating one mechanism.

The Scratchpad is a retrieval surface, not a second course plan. Canonical weekly and combined volumes remain in the main study sequence.
